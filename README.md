# Pong-Game in JavaFX
A classic two-player Pong game where players control paddles and compete to score points by bouncing the ball back and forth.

# Technologies Used 
- Java: Core programming language.
- JavaFX: For GUI and animations.

# How to Play 
Start the Game: Click anywhere on the screen.

Player 1: Use W (up) and S (down) keys.

Player 2: Use UP and DOWN arrow keys.

Objective: Prevent the ball from passing your paddle and score by getting it past your opponent’s paddle.

Winning: First to 3 points wins.

Restart: Press the 🔁 Restart button.

# Prerequisites
- Java 8 or later
- JavaFX SDK
  
# Installation
- Use git clone for cloning the repository to your local machine or simply download and extract the zip.
